# CS4.406 IRE Assignment 1 — Lexical & Semantic Retrieval on MIND & EB-NeRD

A reproducible news-recommendation pipeline covering lexical (BM25) and semantic
(sentence-transformer) candidate generation, an offline evaluation harness, and
feature-based learning-to-rank rerankers, evaluated on the **MIND** (English) and
**EB-NeRD** (Danish) datasets. Predictions are submitted to both Codabench
leaderboards.

## Results summary

| Dataset  | Best leaderboard AUC | Best model                                        |
|----------|----------------------|---------------------------------------------------|
| MIND     | **0.6435**           | LightGBM (behavioural + content), MiniLM embeddings|
| EB-NeRD  | **0.6976**           | LightGBM trained on `ebnerd_large`, multilingual MiniLM |

Full metric tables (AUC / MRR / nDCG@5 / nDCG@10 + diversity / novelty / coverage,
with bootstrap 95% CIs and head/tail slices) are produced by the evaluation harness
and reported in the design note.

## Repository layout

```
src/
  data_pipeline.py     # Q1: download -> unified schema -> temporal split -> feature store
  bm25.py              # Q2: BM25 inverted index + retrieval
  embeddings.py        # Q3: sentence-transformer embeddings + (FAISS/brute-force) ANN retrieval
  features.py          # point-in-time behavioural + content features (leakage-safe)
  rerank.py            # LightGBM learning-to-rank reranker
  evaluate.py          # Q4: AUC/MRR/nDCG + diversity/novelty/coverage + bootstrap CIs + slices
  submit.py            # Q5: generate Codabench prediction files
configs/
  mind.yaml            # dataset paths, model names, feature flags
  ebnerd.yaml
scripts/
  build_pipeline.py    # Q1: ONE-COMMAND rebuild from raw files
tests/
  test_no_leakage.py   # Q9: asserts no future-click leakage in behavioural features
notebooks/             # exploratory Kaggle notebooks (reference)
```

## One-command reproduce

```bash
# 1. install
pip install -r requirements.txt

# 2. rebuild the entire pipeline from raw files (download -> parse -> split -> features)
python scripts/build_pipeline.py --dataset mind    --config configs/mind.yaml
python scripts/build_pipeline.py --dataset ebnerd  --config configs/ebnerd.yaml

# 3. retrieval + recall@K (Q2/Q3)
python -m src.bm25       --dataset mind   --k 50 100 200
python -m src.embeddings --dataset mind   --k 50 100 200

# 4. train reranker + evaluate (Q4)
python -m src.rerank   --dataset mind
python -m src.evaluate --dataset mind

# 5. generate leaderboard submission (Q5)
python -m src.submit --dataset mind --out prediction.zip
```

Swap `--dataset mind` for `--dataset ebnerd` to run the Danish pipeline. Model
choice is per-dataset: `all-MiniLM-L6-v2` (English MIND),
`paraphrase-multilingual-MiniLM-L12-v2` (Danish EB-NeRD).

## Key design decisions

- **Temporal splits only** (never random): MIND trains on Nov 9–14, evaluates on the
  strictly-later Nov 15 dev; EB-NeRD uses the dataset's time-ordered train/val/test.
- **Point-in-time features**: popularity/CTR counted strictly before each impression's
  timestamp via binary search — recomputed per impression (rolling). Frozen popularity
  leaks and degrades under temporal drift.
- **Model choice tracks language**: English-specialised MiniLM beat multilingual E5 on
  MIND; multilingual MiniLM used for Danish EB-NeRD.
- **Reranking vs retrieval are separate**: recall@K measures retrieval from the full
  article pool; the leaderboard task reranks the given in-view slate (AUC/MRR/nDCG).

## Anti-gaming (Q9)

- Behavioural features are reported **with and without** serving-time-unavailable
  signals (frozen vs rolling popularity).
- `tests/test_no_leakage.py` asserts no behavioural feature uses clicks at or after the
  impression timestamp.

## Reproducibility notes

- Compute: Kaggle dual Tesla T4, free tier.
- Large artifacts (embeddings, models, predictions) are **not** committed (see
  `.gitignore`); they are regenerated by the pipeline or stored externally.
